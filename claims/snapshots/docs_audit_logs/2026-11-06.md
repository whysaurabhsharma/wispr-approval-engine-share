Audit Logs for Enterprise admins: Track team membership and join request activity

                Last updated 11 hours ago

Available on:
 Web — the 
admin portal
. There is no Audit Logs page in the desktop or mobile apps.
Audit Logs shows who changed membership, roles, invitations, or join requests in your enterprise, so you can filter the matching records and export them.
Open Audit Logs
Audit Logs requires an enterprise Admin, SuperAdmin, or IT Admin role and shows only your organization's records. Non-admins are redirected home or see “You are not authorized to access this page”.
Open
 the 
admin portal
.
Select
 Audit Logs, then Events if both views are available.
Note:
 Events appears only when it is enabled for your enterprise; Audit Logs stays available to admins either way. Tabs appear only when both views exist, and an unavailable view redirects to the first available one, preferring Events. If neither is available, “Audit logs aren't available for your enterprise yet.” appears without redirecting.

Event types
Select individual types, whole categories, or Select all / Clear all.
Page size
Choose 20 (default), 50, or 100 events; use Load more for additional pages.

Reloads the first page and drops pages opened with Load more.
Choose

 for Member added, Member removed, Member role changed, Member invited, Invitation resent, and Invitation revoked; choose

Select both dates, with the start on or before the end and a range shorter than 92 days; future dates aren't selectable. Invalid dates stop automatic loading and disable exports, but not Refresh. Selecting no event types disables the table, Refresh, and exports; select at least one type to restore them, subject to other restrictions. “No events found for this range.” means no matching records exist for your filters.
Changing dates, event types, or page size restarts pagination. The list refreshes on its own while the browser tab is visible and keeps loaded pages, skipping invalid ranges, empty type selections, and an update already underway. Manual and automatic refresh move preset ranges forward to today, leaving custom ranges unchanged.
Interpret the records
The table and CSV have six columns: Timestamp, Actor, Action, Target, Details, and Event ID. Actor identifies who acted and Target the affected person, organization, or resource; system actions use a service actor rather than a named admin. Names remain as recorded when the event occurred, missing names fall back to IDs and then to an em dash in the table or a blank CSV cell, and there are no separate email-address fields.
Details shows the setting and previous → new value for organization-settings changes, or old → new role for role changes, adding “(in team X)” when a team name is recorded for team-scoped changes. Other actions show an em dash, or a blank Details cell in CSV.
Invitations:
 Member invited is recorded after the email sends, and its JSON record includes the role granted on acceptance. Invitation resent is recorded when an admin resends a pending or failed invite from the Team page; if a Wispr support admin resends on your behalf, that Wispr admin is the actor while the invitation keeps its original inviter. Revoking an already-revoked invitation records nothing, and automatic domain joins that create an invitation can record Member invited instead of Member added.
Join requests:
 Individual and bulk approvals record both Join request approved and Member added for each accepted user, and declines record Join request rejected. A bulk-approval entry that cannot be added is treated as rejected, with no approval or member-added event.
Directory removals:
 Directory-sync removals use a service actor. A removal that would leave no administrator or no billable user is refused and records no Member removed event.
Membership policy:
 Changes to auto-invite or disable team trial record Membership policy changed; saving an unchanged value records nothing.
Warning:
 Changing disable team trial requires an active subscription. Enabling it immediately ends existing members' active trials as well as making new members skip the trial period.
Once set up, audit recording cannot be switched off per enterprise, though events can be lost during recording. Disbanding an organization that never had audit setup produces no audit events.
Export results
Warning:
 If a full page shares one exact timestamp, older tied events can be unreachable and the table and export report incomplete results. Narrow the date range and retry when this happens or when an export reaches its limit.
Set
 the date range and event types you need.
Select
 Export CSV or Export JSON.
Exports cover the whole filtered range, not just loaded rows, up to about 10,000 events regardless of page size. Each Event ID appears only once in the table and exports, which can reduce the export total. JSON contains full event records; CSV uses the six columns above. Downloads are named audit-events-<start>_to_<end>.csv or .json with yyyy-MM-dd dates, and completion confirms the exported count — an empty range downloads a header-only CSV or empty JSON array.
For spreadsheet safety, CSV values starting with =, +, -, @, tab, or carriage return are quoted and prefixed with an apostrophe, which may appear in your spreadsheet.
If an export fails, select the export button again to retry. The error may say “Failed to export audit events. Please try again.” or give a more specific message.
If events aren't available
Events is enabled but not set up
Events stays visible with exports disabled, and the setup message depends on your domain status:
No linked domains:
 Contact enterprise@wispr.ai to add one.
Unverified domain:
 Check status under Settings → Organization and contact enterprise@wispr.ai for help; Wispr completes verification.
Setup pending:
 Contact enterprise@wispr.ai if this persists.
The event list won't load
With event types selected, a loading failure before any rows load replaces the filters, Refresh, and exports with View audit events; this does not apply to the setup state above. Failed refreshes or Load more attempts leave already-loaded rows and controls visible.
Select
 View audit events to open your organization's events in a new browser tab.
If “Couldn’t open the events viewer. Please try again.” appears, select it again; the message can also mean the opening request failed, not just that the window was blocked or closed.
